# The Tea Shop – Website Project

A fictional tea shop website built as part of my web design portfolio.
This project focuses on beginner-level HTML and CSS, planned using a
site diagram and homepage wireframe before coding.

## 🎯 Project Goal
Practice planning and building a simple, responsive website from
scratch — starting with a sitemap and wireframe, then writing clean
HTML and CSS by hand.
